🎯 快速开始
================================================================================

【每日自动交易】（最常用）
python run_auto_trading.py
  └─ 功能：完整的自动交易流程
     • 下载最新数据
     • 生成交易信号
     • 执行买入/卖出
     • 生成每日报告
     • 自动止损监控
  └─ 使用场景：每天市场开盘前运行一次
  └─ 运行时间：约2-3分钟


【主菜单】（推荐新手使用）
python run_menu.py
  └─ 功能：交互式菜单，包含所有功能
     1. 自动交易
     2. 查看仪表板
     3. 检查账户状态
     4. 市场分析
     5. 归因分析
     6. 数据质量检查
     7. 参数优化
     8. 重新训练模型
     9. 回测
     0. 初始设置
  └─ 使用场景：不确定要运行什么时
  └─ 运行时间：根据选择的功能不同


================================================================================
🔧 核心功能命令
================================================================================

【模型训练】
python run_retrain_models.py
  └─ 功能：重新训练所有6个因子模型
     • 下载最新市场数据
     • 训练Momentum、Trend、Volatility、Volume、Market、Alpha模型
     • 使用XGBoost + LightGBM + CatBoost集成
  └─ 使用场景：
     • 每周日晚上运行（建议20:00）
     • 模型表现下降时
     • 市场环境发生重大变化时
  └─ 运行时间：20-30秒
  └─ 输出：6个新模型保存到 research/artifacts/


【生成交易信号】
cd research && python get_daily_signals_multi_factor.py
  └─ 功能：生成当日交易信号（不执行交易）
     • 使用6个因子模型预测
     • FinBERT新闻情绪分析
     • 长期趋势过滤
     • 输出推荐股票列表
  └─ 使用场景：
     • 只想看推荐，不想自动交易
     • 手动决策是否交易
  └─ 运行时间：约30-60秒
  └─ 输出：signals_multi_factor_YYYYMMDD.json


================================================================================
📊 监控和检查命令
================================================================================

【检查监控状态】⭐ 新增
python check_monitor_status.py
  └─ 功能：全面检查系统运行状态
     • 计划任务是否在运行
     • Python进程状态
     • 最近的监控日志
     • 实时账户状态和持仓
  └─ 使用场景：
     • 想知道监控是否正在运行
     • 检查当前持仓情况
     • 查看最近的交易日志
  └─ 运行时间：5秒


【查看账户状态】
python check_account.py
  └─ 功能：详细的账户信息
     • 账户资产、现金、持仓
     • 每个持仓的盈亏情况
     • 运营成本（API费用）
  └─ 使用场景：快速查看账户概况
  └─ 运行时间：2-3秒


【手动止损检查】
python monitor_dynamic_trading.py
  └─ 功能：检查并执行动态交易策略
     • 检查每个持仓是否触发止损（-2.5%）或止盈（+2.5%）
     • 检查账户是否触发最大日内亏损（-3%）
     • 美股 16:00 ET 自动平仓
     • 自动平仓触发条件的股票
  └─ 使用场景：
     • 手动检查是否需要止损/止盈
     • 计划任务失效时手动运行
  └─ 运行时间：5秒
  └─ 注意：通常由计划任务自动运行，每5分钟一次


【监控Paper Trading表现】
python monitor_paper_trading.py
  └─ 功能：生成性能报告和可视化
     • 生成收益曲线图
     • 计算夏普比率、最大回撤
     • 对比回测结果
  └─ 使用场景：查看策略表现
  └─ 运行时间：10-15秒


================================================================================
📈 分析和诊断命令
================================================================================

【分析亏损原因】
python analyze_losses.py
  └─ 功能：深度分析交易历史
     • 盈亏统计（胜率、盈利因子）
     • 最佳/最差股票排名
     • 按退出原因分析
     • 时间维度分析
     • 诊断问题并给出建议
  └─ 使用场景：
     • 账户亏损时找原因
     • 优化策略参数
  └─ 运行时间：5秒


【检查特定股票表现】
python check_loss_stocks.py
  └─ 功能：查看UNH、ORCL等特定股票的实际表现
     • 买入价 vs 卖出价
     • 实际涨跌幅
  └─ 使用场景：验证为什么某些股票亏损
  └─ 运行时间：3-5秒
  └─ 注意：可修改脚本查看其他股票


【数据质量检查】
python data_quality_monitor.py
  └─ 功能：检查数据完整性
     • 缺失值检查
     • 数据新鲜度
     • 特征计算正确性
  └─ 使用场景：
     • 模型预测异常时
     • 定期数据健康检查
  └─ 运行时间：10秒

🗂️ 文件和日志位置
================================================================================

【重要文件】
├─ config_alpaca.py          - Alpaca API配置
├─ config_finnhub.py         - Finnhub新闻API配置
├─ research/
│  ├─ config.yaml            - 模型配置
│  ├─ config_trend_filters.py - 趋势过滤器配置
│  └─ artifacts/
│     ├─ ensemble_momentum.pkl - 动量因子模型
│     ├─ ensemble_trend.pkl    - 趋势因子模型
│     ├─ ensemble_volatility.pkl
│     ├─ ensemble_volume.pkl
│     ├─ ensemble_market.pkl
│     └─ ensemble_alpha.pkl
└─ trading_logs/
   ├─ daily_report_YYYYMMDD.txt     - 每日报告
   ├─ stop_loss_events_YYYYMMDD.json - 止损事件
   ├─ trades_YYYYMMDD_HHMMSS.json   - 交易记录
   └─ daily_signals_detailed.csv    - 信号详情


【日志文件说明】
• daily_report_YYYYMMDD.txt
  → 每日交易总结，包括持仓、盈亏

• stop_loss_events_YYYYMMDD.json
  → 记录所有止损事件（单股止损、最大日内亏损）

• trades_YYYYMMDD_HHMMSS.json
  → 详细的交易执行记录（信号、实际成交价格、因子贡献）

• daily_signals_detailed.csv
  → 每日信号的累积记录，可用于回测分析

⏰ 建议的运行时间表
================================================================================

【每日自动运行】
• 20:00 (美东时间) - python run_auto_trading.py
  → 市场收盘后，下载数据，生成明日信号

• 开盘前 - 系统自动执行交易
  → AlpacaDynamicTradingMonitor计划任务

• 每5分钟 - python monitor_dynamic_trading.py --auto
  → DynamicTradingMonitor 计划任务自动运行（止损/止盈/最大日内亏损/EOD 平仓）


【每周运行】
• 每周日 20:00 - python run_retrain_models.py
  → 使用最新一周数据重新训练模型


【按需运行】
• python check_monitor_status.py - 每天检查1-2次
• python check_account.py - 随时查看账户
• python analyze_losses.py - 亏损时运行诊断

📝 重要参数配置
================================================================================

【信心阈值】（research/get_daily_signals_multi_factor.py:498）
min_confidence = 0.0015  # 0.15%
  → 降低后能选出更多股票
  → 提高后更谨慎，但可能选不出股票

【止损参数】（monitor_dynamic_trading.py）
STOP_LOSS_PCT = 0.025        # 单股止损 -2.5%
TAKE_PROFIT_PCT = 0.025      # 单股止盈 +2.5%
MAX_DAILY_LOSS_PCT = 0.03    # 最大日内亏损 -3%
EOD_CLOSE_TIME = 16:00 ET    # 美股收盘自动平仓（夏令时自动处理）

【长期趋势过滤】（research/config_trend_filters.py）
FILTER_7D_MIN_RETURN = -3.0   # 7天回报下限
FILTER_14D_MIN_RETURN = -6.0  # 14天回报下限
FILTER_TREND_STRENGTH_MIN = -3.0


================================================================================
🆘 常见问题解决
================================================================================

【问题1：选不出股票】
→ 降低信心阈值：修改 research/get_daily_signals_multi_factor.py
   min_confidence = 0.0015  # 从0.25%降到0.15%

【问题2：监控没有运行】
→ 运行：python check_monitor_status.py
   查看计划任务状态，如果没有则需要重新设置

【问题3：账户一直亏损】
→ 运行：python analyze_losses.py
   查看详细分析和改进建议

【问题4：编码错误（中文乱码）】
→ 使用Python版本的脚本（run_*.py），不要用.bat文件

【问题5：API配额超限】
→ Finnhub: 60次/分钟（通常够用）
   Alpaca: Paper Trading无限制
