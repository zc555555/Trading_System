========================================================================
                      重要：如何正确运行脚本
========================================================================

问题：在 PowerShell 中运行 .bat 文件会出现编码错误！

PowerShell 的提示符是：PS C:\Users\...>  ❌ 错误
CMD 的提示符是：     C:\Users\...>  ✓ 正确

========================================================================
                      推荐方法（最简单）
========================================================================

直接双击运行以下文件（会自动在CMD中打开）：

  ✓ RUN_MAIN_MENU.cmd      - 打开主菜单
  ✓ RUN_AUTO_TRADING.cmd   - 运行自动交易

这两个文件会自动在正确的环境（CMD）中运行。

========================================================================
                      方法2：手动打开CMD
========================================================================

1. 按 Win + R 键
2. 输入：cmd
3. 按回车（会打开黑色的CMD窗口）
4. 在CMD中输入：
   cd c:\Users\13785\OneDrive\Desktop\stock_predict
   main_menu.bat

========================================================================
                      方法3：从文件管理器
========================================================================

1. 打开文件夹：c:\Users\13785\OneDrive\Desktop\stock_predict
2. 直接双击 main_menu.bat 或 auto_trading.bat
   （会自动在CMD中运行）

========================================================================
                      不要这样做 ❌
========================================================================

❌ 不要在 PowerShell 中运行 .bat 文件
❌ 不要使用 .\auto_trading.bat（PowerShell语法）
❌ 不要在 VSCode 的 PowerShell 终端中运行

========================================================================
                      日常使用
========================================================================

每天 21:00 运行交易：
  → 双击 RUN_AUTO_TRADING.cmd

查看菜单/其他功能：
  → 双击 RUN_MAIN_MENU.cmd

就这么简单！
