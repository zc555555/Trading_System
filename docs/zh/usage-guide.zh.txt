📌 简单规则：什么时候运行什么？

================================================================================
                              首次使用（只需一次）
================================================================================

步骤1：设置监控系统
  运行：main_menu.bat → 按 [S]
  说明：设置定时任务，自动监控持仓
  备注：必须以管理员身份运行

步骤2：安装依赖（如果还没装）
  运行：install_new_features.bat
  说明：安装必要的Python包

================================================================================
                              日常使用（每天）
================================================================================

🌙 晚上21:00 - 自动交易
--------------------------------------------------
运行：main_menu.bat → 按 [1]
或直接运行：auto_trading.bat

作用：
  ✓ 分析60只股票
  ✓ 应用长期趋势过滤
  ✓ 结合新闻情绪分析
  ✓ 平掉旧持仓
  ✓ 买入4只新股票

运行频率：每天晚上21:00
耗时：约5-10分钟

--------------------------------------------------

📊 随时查看 - 实时仪表板
--------------------------------------------------
运行：main_menu.bat → 按 [2]
或直接运行：start_dashboard.bat

作用：
  ✓ 实时持仓状态
  ✓ 今日盈亏
  ✓ 新闻情绪
  ✓ 风险指标

运行频率：想看就运行，可以一直开着
备注：会自动刷新

--------------------------------------------------

--------------------------------------------------

作用：
  ✓ 快速查看当前持仓
  ✓ 查看盈亏情况

运行频率：随时
耗时：几秒钟

================================================================================
                              自动运行（无需手动）
================================================================================

🤖 监控系统 - 自动运行
--------------------------------------------------
任务名称：AlpacaDynamicTradingMonitor
运行时段：14:30 - 21:05（每5分钟）

自动功能：
  ✓ 止盈：盈利 > 2.5% 自动平仓
  ✓ 止损：亏损 > 2.5% 自动平仓
  ✓ 最大亏损：总亏损 > 3% 全部平仓
  ✓ 21:00：自动平仓所有持仓

无需手动运行！
首次设置后自动工作

查看任务：
  schtasks /query /tn AlpacaDynamicTradingMonitor

删除任务（如需停止）：
  schtasks /delete /tn AlpacaDynamicTradingMonitor /f

================================================================================
                              故障排除
================================================================================

问题1：仪表板打不开
解决：
  1. 检查是否安装了streamlit：pip install streamlit
  2. 查看命令行窗口的错误信息
  3. 尝试手动运行：streamlit run dashboard.py

问题2：监控系统没有运行
解决：
  1. 检查定时任务：schtasks /query /tn AlpacaDynamicTradingMonitor
  2. 重新设置：setup_smart_monitor.bat（以管理员身份）
  3. 查看日志：alerts/alerts_YYYYMMDD.log

问题3：交易失败
解决：
  1. 检查Alpaca连接：运行check_current_performance.py
  2. 查看API密钥配置：config_alpaca.py
  3. 检查网络连接

问题4：找不到数据
解决：
  1. 运行数据质量检查：check_data_quality.bat
  2. 检查research/data/目录
  3. 可能需要重新下载数据

问题5：模型预测不准
解决：
  1. 运行归因分析，查看哪里出问题
  2. 检查市场状态，可能需要调整参数
  3. 运行重新训练，更新模型
  4. 如果持续不准，考虑参数优化
